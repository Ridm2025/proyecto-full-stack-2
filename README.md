# Sting Tech Solutions V2 — Evaluación Parcial 2 (DSY1104)

Migración académica desde Sting Tech (HTML/CSS) a React con Next.js, tomando como referencia la estructura de `mi-tienda`.

## Ejecutar en Windows / VS Code

1. Instala Node.js reciente.
2. Abre la carpeta `sting-tech-v2` en VS Code.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre `http://localhost:3000`.

## Implementado

- React/Next.js con componentes reutilizables y props.
- Bootstrap y diseño adaptable.
- Portada y servicios adaptados al Sting Tech original; logo original conservado.
- Catálogo local con búsqueda, categorías y ofertas.
- Carrito con estado y almacenamiento local del navegador.
- Checkout validado, comprobante de orden simulada en la sesión (sin pago real).
- Panel CRUD de productos local, sin usuarios ni autenticación; es solo demostrativo.
- Formularios de contacto y soporte: validación visual sin backend ni envío real.

## Pendiente para cumplir completamente la pauta

- Jasmine y Karma: configuración, al menos 10 pruebas ejecutadas y reporte de cobertura.
- ERS V2 y documento de cobertura de pruebas.
- Autenticación, seguridad y backend integrado si el docente exige funcionamiento real.
- Flujo específico de pago fallido, detalles de producto y pruebas de accesibilidad.

## Seguridad

No introducir información de pago real ni datos personales reales. El panel de administración es una demo sin autenticación. Los precios e inventario son ficticios.
